Safe tmux pane operations for Claude Code: send commands, restart individual panes without killing others, inspect state. Built to dodge the multi-line shell-mangling bug that occurs when Claude Code's Bash tool pipes commands through tmux send-keys. Use when you need to: operate on a tmux session, restart a scheduler/monitor while preserving training panes, inspect what's running in each pane, or safely send a command to a specific pane. Use when asked to "restart tmux", "send command to tmux", "check tmux status", or "restart scheduler without killing training".
